# Changelog

## v1.1 — 2026-07-21
- Added zero-interaction default as binding design principle (§2.7)
- Progressive identity verification levels (instant Level 0 registration)
- Social/institutional key recovery (context-shard escrow + cross-signing)
- Implicit trust grants: transactional, introduction-forwarding, context inheritance
- Adaptive connection-request rate limits
- Threads restructured as signed append-only event logs (simplified event-graph)
- Client-Server (HCS) / Federation (HFA) API split
- Mandatory sliding sync
- OIDC/OAuth 2.0 authentication
- Day-one bidirectional SMTP bridge; generic Bridge API
- 90-day grace redirect on context revocation
- Link handling: warn-and-display instead of hard rejection
- Recipient-configurable retention with non-delivery manifests
- KDS push invalidation on key rotation
- Governance: HERALD Foundation + HIP process

## v1.0 — initial draft
- GID identity system with context addresses
- Three-tier trust chain
- HMF envelope format, HRTP transport
- Federated server architecture
